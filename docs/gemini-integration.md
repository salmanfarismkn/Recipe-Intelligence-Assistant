# Gemini integration and grounded responses

The application includes a small Google Gemini provider and a typed
natural-language bridge. FastAPI exposes the provider through the conversational
API; deterministic retrieval, matching, statistics, and substitution remain
independently callable and do not require Gemini.

## Configuration

Install the package and test dependencies:

```powershell
python -m pip install -e ".[test]"
```

Set these environment variables to enable Gemini:

| Variable | Required | Meaning |
|---|---|---|
| `LLM_ENABLED` | No | `true` enables Gemini; defaults to `false`. Accepts `true`/`false`, `1`/`0`, or `yes`/`no`. |
| `GEMINI_API_KEY` | When enabled | Google Gemini API key. It is not logged. |
| `GEMINI_MODEL` | When enabled | Model name for the Gemini Developer API. |

When enabled, the application makes one synchronous structured-JSON request at
a time, with a 20-second HTTP timeout, a 1,024-token output limit, and a 20,000
character response limit. Automatic retries are disabled. The adapter maps
timeouts, rate limits, transport failures, API errors, and malformed responses
to explicit provider exceptions. The dependency is `google-genai` (version 1.x).

Use `provider_from_environment()` to configure the provider. When LLM use is
disabled, the API supports a bounded deterministic parser and explicit
contextual follow-ups; unsupported phrasing asks for clarification or returns
an availability error. Deterministic services can always be called directly.

## Grounding and validation

`assistant.py` validates a fixed typed interpretation schema and requires all
extracted entities to occur as complete normalized phrases in the user's
request. Recipe references are resolved against SQLite before substitution.
The interpreter has no database or other tools.

Response generation gives Gemini only compact application-created facts and
asks it to select a constrained opening and reproduce every fact ID exactly
once. It cannot provide free-form claims. The application rejects malformed or
unknown fact references and renders the facts, recipe IDs, statistics, and
evidence from application-owned records in canonical order. Any provider or
validation failure falls back to the deterministic rendering. Dataset-derived
content is marked untrusted in prompts.

The Gemini response role is intentionally narrow: it does not calculate,
rewrite, or summarize facts. Consequently the response layer prioritizes
grounding over conversational prose. The application validates ranking
preferences and applies them deterministically after hard-constraint eligibility.
Request extraction quality and live Gemini behavior have not been evaluated
without configured credentials.

## Reproducible evaluation

Download the pinned archive, then run the evaluation script against it:

```powershell
python scripts\download_dataset.py
python scripts\evaluate_llm_grounding.py data\raw\recipes_raw.zip
```

The script imports the full archive into an in-memory database, checks entity
validation, verified search references, rejection of a fabricated fact ID, and
preservation of a peanut exclusion in actual matching results. It uses
deterministic test providers, not Gemini, and exits nonzero if any check fails.
It prints the dataset snapshot identity, record counts, IDs, and measured
candidate/result counts; it does not estimate model accuracy.

On the pinned archive, the executed evaluation loaded all **125,164** records
(AR 39,802; Epi 25,323; FN 60,039). The current check output, including actual
IDs and candidate counts, is generated by the command above and included in
[`reports/evaluation_report.json`](../reports/evaluation_report.json) where
applicable.
This is a deterministic integration evaluation, not a live Gemini connectivity
test or a measurement of natural-language model accuracy.

Run automated tests with:

```powershell
python -m pytest -q
```

Tests mock the provider and make no Gemini network calls.

## Limitations

- No Gemini key/model was configured during this evaluation, so live API
  connectivity and model accessibility were not verified.
- Generated prose is limited to fixed application-owned facts and one selected
  opening; Gemini does not paraphrase evidence.
- Matching ranking preferences are applied deterministically after hard
  constraints; they cannot make an ineligible recipe eligible.
- Conversation state and session lifecycle are documented in
  [API and conversations](./api-and-conversations.md).
- Dataset text is untrusted prompt input; the model has no tools, but prompt
  injection cannot be eliminated as a general property of LLMs.
